📡 Google Doc Radar

Local API for ingesting and querying Google Docs content

Write

Ingest Document

POST /api/docs

Upsert a document (or a single tab of a multi-tab document).

document_id string required
Google Doc ID (from the URL)
tab_id string
Tab identifier (e.g. t.0). Empty string for single-tab docs.
tab_name string
Display name of the tab
title string
Document title
content string
Extracted text content
url string
Canonical document URL
{
  "document_id": "1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms",
  "tab_id": "t.0",
  "tab_name": "Meeting Notes",
  "title": "Q4 Planning",
  "content": "Full text of the document...",
  "url": "https://docs.google.com/document/d/1BxiMVs0XRA5n/edit"
}

Response: {"upserted": 1}

Read

Query Documents (JSON)

GET /api/read
document_id / doc_id
Filter by document ID
tab_id
Filter by tab ID
tab_name
Filter by tab name (substring match)
from / since / start
Start time (YYYY-MM-DD, RFC3339, or Unix timestamp)
to / until / end
End time
limit
Max results (default: 1000)
curl "http://localhost:9906/api/read?document_id=1BxiMVs0XRA5n"

Query Documents (Markdown)

GET /api/read/md

Same parameters as /api/read. Defaults to last 7 days if no time range given.

Query Documents (HTML)

GET /api/read/html

Same parameters as /api/read. Renders as an HTML page with outline sidebar.

Search

Full-text Search

GET /api/search
q / query string required
Search term (matches against title and content)
limit
Max results (default: 20)
curl "http://localhost:9906/api/search?q=meeting+notes"

Examples

# Ingest a document
curl -X POST http://localhost:9906/api/docs \
  -H 'Content-Type: application/json' \
  -d '{"document_id":"abc123","title":"My Doc","content":"Hello world"}'

# Get all tabs of a document
curl "http://localhost:9906/api/read?document_id=abc123"

# Search across all documents
curl "http://localhost:9906/api/search?q=hello"

# Read as markdown
curl "http://localhost:9906/api/read/md?from=2026-01-01"
