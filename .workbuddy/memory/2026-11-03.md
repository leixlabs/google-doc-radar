# 2026-11-03

## server: 保存到 DB 的同时写入 Markdown 文件

- 新增 `server/markdown_export.go`：`mdExporter` 把每条 (document_id, tab_id) 记录镜像成 `<title> [<doc_id> - <tab_id>].md`。
  - 文件名内嵌 key（docID + tabID，非 tab name），改名时 `removeStale` 删除旧文件，避免 `Title (1).md` 堆积。
  - 原子写（temp + rename），权限 0644；YAML front matter（document_id/tab_id/tab_name/title/url/created_at/updated_at/source）。
  - 正文直接使用 Google Docs markdown 导出内容，不再重复加 H1。
- `main.go`：`handlePostDocs(db, exp)`，upsert 后 `fetchDoc` 回读拿到 DB 时间戳再落盘；镜像失败不影响 DB 写入，响应返回 `markdown` / `markdown_error`。
- 新 flag：`--md-dir`（默认取 `GDOC_MD_DIR` 环境变量，空=禁用）、`--md-backfill`（启动时导出历史行，可用 `Backfill()`）。
- 同步更新：docker-compose（`GDOC_MD_DIR=/data/md`）、launchd plist（`--md-dir /Users/lei/dev/db/google-doc-radar/md`）、README、api-docs.html；重新编译了仓库内的 `server/google-doc-radar-server`。
- 测试：`markdown_export_test.go` 覆盖写入/改名替换/multi-tab/禁用/backfill/文件名清洗；真实 DB 副本 91 行 backfill 出 91 文件，无删错。
